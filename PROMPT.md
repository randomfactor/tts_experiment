## Application Description
This project is a React-based text-to-speech playground that uses the browser Web Speech API (`SpeechSynthesisUtterance`).

You can:
- Enter custom text to speak.
- Choose a voice and language.
- Adjust speech parameters: rate, pitch, and volume.
- Control playback with Speak, Pause, Resume, and Stop.

## Project Structure
Top-level directories and files:

- `package.json`: project metadata, dependencies, and npm scripts.
- `public/`: static assets and HTML template.
- `src/`: React source code.
- `build/`: production build output (generated by `npm run build`).
- `README.md`: Create React App baseline documentation.
- `PROMPT.md`: project-specific notes and setup guidance.

Key source files in `src/`:

- `App.js`: main application logic and speech controls.
- `App.css`: styles for the app UI.
- `index.js`: React app entry point.
- `index.css`: global styles.
- `App.test.js`, `setupTests.js`: testing setup and sample test.

## Install And Build From Git
Prerequisites:

- Node.js and npm installed (Node via nvm is recommended).

1. Clone the repository:

```bash
git clone <your-repo-url>
cd tts_experiment
```

2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm start
```

4. Create a production build:

```bash
npm run build
```

5. (Optional) Run tests:

```bash
npm test
```
