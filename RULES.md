# Rules for saving audio output

1. Utterances from SpeechSynthesisUtterance cannot be recorded to files

# Rules for saving audio from deepgram

1. suggested file name should be of form tts_YYYYMMDD_HHmmss_first_four_words_of.mp3
  - YYYYMMDD is date
  - HHmmss is military time (for instance 000001 is one second after midnight)
  - first_four_words_of would be the first four words from the "Text to speak" input
